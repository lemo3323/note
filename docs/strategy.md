# 収益化の方針（YouTube は入口、note で収益化）

作成：2026-10-28。運営者の指示をそのまま方針として残したもの。変えるときはこのファイルを直し、`CLAUDE.md` と `config/channel.note.yaml` の値も合わせる。

## 役割分担

| 媒体 | 役割 | 中身 |
|---|---|---|
| YouTube（波音ひより 狙い目チャンネル） | **入口** | 無料で狙い目の基本を紹介。説明文から、その機種の note 記事と月額マガジンへ案内する |
| note | **収益化** | 有料記事（単発・月額マガジン）。YouTube では出さない深い情報（特殊狙い・優遇狙い・自作期待値表 など） |

YouTube の広告収益は審査が通るまで当てにしない。note は審査なしで初日から売れるので、収益の柱は note に置く。

## 価格

| 商品 | 価格 | 中身 |
|---|---|---|
| 単発記事 | **200円** | 1機種の完全版、または特殊狙い・優遇狙いのまとめ |
| 月額マガジン（創刊メンバー） | **590円／月** | 今週の狙い目まとめ・狙い目変更のお知らせ・新台初週速報・単発記事の読み放題 |
| 月額マガジン（通常） | **790円／月** | 会員が **100人を超えたら** 590円 → 790円 に上げる（既存の創刊メンバーの扱いは note の仕様を確認して決める） |
| 期待値表つきプラン | **980円／月** | 月額マガジンの中身＋自作の期待値表 |

価格は `config/channel.note.yaml` の `note.price_single` / `note.price_monthly` / `note.price_monthly_after` / `note.price_premium` に入れ、記事とキットはそこから読む。

## 売り（他の狙い目情報との違い）

1. **特殊狙い・優遇狙い**（リセット・有利区間・引き戻し・据え置き・示唆・優遇/冷遇 など）。いちばん力を入れて調べる
2. **自作の期待値表**（シミュレーション＋答え合わせ。他サイトの表の写しではない）
3. **標準ボーダーと強気ボーダーの2本立て**（運営者の立ち回りの考え方 `config/strategy_notes.md` が根拠）
4. **新台初週速報**（判明している天井・狙い目・やめどき。分からない所は「調査中」と書く）
5. **狙い目変更のお知らせ**（シートを書き換えた台を毎週まとめる）
6. **ホールでの探し方**（どこを見れば狙える台か分かるか）
7. **初心者向け機種ガイド**（スペック・打ち方・天井のしくみ）

1〜5 は有料（単発・月額）、6・7 は無料記事にして、最後に有料記事と月額へ案内する。

## 12週間の目標

| 週 | やること | 目標 |
|---|---|---|
| 1〜2週 | 単発記事5本＋無料記事3本を出す | 単発5本・無料3本 |
| 3〜4週 | 月額マガジンを始める（創刊メンバー590円） | 会員 **10人** |
| 5〜8週 | 期待値表つきの機種を増やす | 期待値表 **5機種**・会員 **30人** |
| 9〜12週 | 期待値表を広げる | 期待値表 **20機種**・会員 **100人前後**（100人を超えたら790円に） |

## 守ること（YouTube と共通）

- 期待値は長い目で見た平均の目安で、1回の結果を保証しない。ハマることもある
- 18歳未満は遊技できない。のめり込みに注意
- 実在のホール名・機種画像・実機画像は出さない（画像はひよりと図だけ）
- 他サイトの情報は事実（数値・条件・仕様）だけを自分の言葉で書く。文章・表を写さない。有料会員限定の内容は使わない
- メモ（狙い目シート）と調べた情報が食い違ったら、メモを優先し運営者に知らせる
