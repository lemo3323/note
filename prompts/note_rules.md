# 共通の決まり（すべての note 記事）

- 材料の優先順位：①狙い目シート（運営者のメモ）②調べた情報（facts。confidence が high か single のものだけ）③自作の期待値データ。材料に無い恩恵・解析・数値は書かない
- シートと調べた情報が食い違うときは**シートを優先**する（conflicts に挙がっているもの）。調べた情報の方の値は書かない
- 10以上の数字は、材料（シート・facts・期待値表）にある数字だけを使う。計算して新しい数字を作らない（コードが確かめ、無ければ作り直しになる）
- confidence が single、または provisional（暫定・調査中）の情報は「〜とされている」「〜という情報がある」と書き、断定しない
- 他サイトの文章・表をそのまま写さない。事実（数値・条件・仕様）だけを自分の言葉で書く。有料会員限定の内容は使わない
- 各セクションの sources には、そのセクションで使った facts の出典 URL を入れる（材料に無い URL は書かない）
- 文体：読みやすい標準語（です・ます）。ひよりの口調（くだけた話し言葉）は、見出しの一言（hiyori）とまとめ（closing）だけ
- 初心者向けに、CZ・天井・スルー・駆け抜け・有利区間などの言葉は最初に出たとき短く言い換える。ホールでどこを見れば分かるか（液晶・データカウンター・メニュー画面・PUSHボタン など）を添える
- 勝ちを保証する言い方（必ず勝てる・稼げる・儲かる など）をしない。実在のホール名・他の配信者名を出さない
- 注意書き（期待値は目安で結果を保証しない、ハマることもある、18歳未満は遊技不可、のめり込み注意）・参考・運営者の考え方・自作期待値表・「ここから有料」の区切りは**コードが入れる**ので書かない
- 画像：images には見出し画像1枚（slot: header。text は8〜12字の大きな文言、subtext は20字以内）だけを書く。
  本文の画像は、各セクションの hiyori（ひよりの一言・20〜30字）ごとにコードが作る（ひより＋吹き出し）。
  hiyori_emotion でその一言の表情を選ぶ：happy（明るく）/ surprised（驚き・注意）/ relaxed（やさしく）/ neutral（落ち着いて）/ angry / sad
- 出力は次の JSON スキーマに合う JSON だけを ```json のコードブロック1つで出す

