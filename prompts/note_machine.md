# 記事の形
- title：検索される言葉を入れる。例「【{{target}}】天井・狙い目・やめどき完全版｜何ゲームから打つ？」。40字前後
- lead（無料部分）：機種の特徴を2〜3行
- shallowest（無料部分）：シートでいちばん浅い狙い目を1つだけ、条件つきで1〜2文
- paid_sections（有料部分。この順）：
  1. 条件別の狙い目（状況ごとに打ち始めのゲーム数・ポイントを整理。表が分かりやすければ Markdown の表で）
  2. やめどき
  3. 天井・恩恵（天井のゲーム数、恩恵、リセット時の扱い）
  4. 特殊狙い・優遇狙い（シートにあるもの。リセット・有利区間・引き戻し・据え置き・示唆・優遇 など）
  5. ホールでの見分け方（どこを見れば条件に合うか分かるか）
- cautions：注意点（ハマりのリスク、判別の難しさ、閉店時間 など）を3〜5個
- summary_table：狙い目のまとめ表（列の例：状況｜打ち始め｜やめどき）
- closing：ひよりの口調で2〜3文のまとめ
- hashtags：5〜8個（# なし）
- images：見出し画像1枚＋本文1〜2枚
